# Aulas de Programador de Sistemas - SENAC

## Aula 02 - Sistemas de Informação

### Definição do Sistema de Informações

Um sistema de informação (SI) é um conjunto integrado de componentes para coletar, processar, armazenar e distribuir informações que apoiam a tomada de decisões e o controle em uma organização. Os sistemas de informação combinam hardware, software, dados, pessoas e processos para criar soluções que melhoram a eficiência operacional.

**Componentes principais de um SI:**
- **Hardware**: computadores, servidores, dispositivos de rede
- **Software**: programas, aplicações, sistemas operacionais
- **Dados**: informações estruturadas e não estruturadas
- **Pessoas**: usuários, desenvolvedores, gestores
- **Processos**: procedimentos e fluxos de trabalho

---

### Importância dos Sistemas de Informações nas Organizações

Os sistemas de informação são críticos para o sucesso organizacional nos dias atuais:

1. **Melhoria da Eficiência**: Automação de processos reduz tempo e custos operacionais
2. **Tomada de Decisão**: Acesso rápido a dados e relatórios facilita decisões estratégicas
3. **Competitividade**: SI avançados diferenciam as empresas no mercado
4. **Escalabilidade**: Permitem que as organizações cresçam sem aumentar proporcionalmente os custos
5. **Inovação**: Habilitam o desenvolvimento de novos produtos e serviços
6. **Segurança**: Protegem dados sensíveis e informações confidenciais
7. **Comunicação**: Facilitam a colaboração entre departamentos e localizações

---

### Tipos de Sistemas de Informação

Os sistemas de informação são classificados conforme seu nível estratégico e função:

#### 1. **Sistemas de Nível Operacional**
- **Processamento de Transações (TPS - Transaction Processing System)**
  - Processam transações diárias rotineiras
  - Exemplo: sistemas de vendas, folha de pagamento, controle de estoque
  - Usuários: funcionários operacionais

#### 2. **Sistemas de Nível Tático/Gerencial**
- **Sistemas de Informações Gerenciais (MIS - Management Information System)**
  - Geram relatórios para gestores
  - Apoiam decisões de curto prazo
  - Exemplo: relatórios de vendas, análise de desempenho

- **Sistemas de Apoio à Decisão (DSS - Decision Support System)**
  - Análise de dados complexos
  - Facilitam decisões semiestruturadas
  - Exemplo: simulações, previsões de vendas
